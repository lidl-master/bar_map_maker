# Wave 4 brief: standalone app and UX

Bars (from [bars.md](bars.md) and the kickoff prompt): Windows installer and portable `.exe`; works fully offline; cold start ≤ 3 s; 32×32 export ≤ 20 s; 32×32 open ≤ 10 s; smooth sculpting on 32×32; Share ≤ 50 MB; every automatable BAR checklist item passes (G7); a zero-context "new BAR mapper" persona completes all four task cards (G5).

Rules on top of the usual builder rules:
- The BAR folder is written only by the existing confirmed Install. Play-test and Check map must work **without** installing: run the engine isolated, with the exported archive's folder added as an extra data dir.
- Only small npm packages (< 50 MB unpacked, versions at least two weeks old, `--save-exact`) are pre-approved. Anything bigger, or any download at build time beyond that, goes on a list for the user instead of being installed.
- Big runtime files (engine run dirs, caches) live next to the export folder (on D: here), not in `%APPDATA%`.
