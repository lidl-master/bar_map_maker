    How to make a BAR map

    1. Create a map (New) – pick a size, number of players, symmetry and a starting terrain.
    2. Sculpt with the brushes on the left. Everything is mirrored by the Symmetry setting so the map stays fair.
    3. Check pathing: switch Show → Pathing. Green = all ground units, yellow = bots only (too steep for tanks), red = cliffs nobody can climb, light blue = shallow water units can wade, dark blue = deep water (ships/hover).
    4. Place resources: Metal spots (M), Geothermal vents (G) and Start positions (T) – or use Generate → Auto-place resources.
    5. Texture: choose a look in the Texture tab and paint materials (P) such as paths or rock.
    6. Export → Playable map (.sdz) and copy the file into your BAR maps folder:
      %LOCALAPPDATA%\Programs\Beyond-All-Reason\data\maps\
      (If you installed BAR elsewhere, use <install folder>\data\maps.) Restart the game / lobby and pick the map in a skirmish.

    Mouse & keyboard

    Left drag use tool
    Right / middle drag or Space+drag – pan
    Wheel zoom · Shift+Wheel brush size
    [ ] brush size · Shift invert raise/lower
    Alt+click (Flatten) – pick height
    Right-click a resource – delete it
    Del delete selected · Home fit view
    Ctrl+Z undo · Ctrl+Y redo · Ctrl+S save

    Good to know

    • Heights are in elmos (BAR's world units). Water is everything below 0. A tank is about 30–40 elmos long; 1 map unit = 512 elmos.
    • Metal spot values are what players see in game (a T1 extractor on a "2.0" spot makes 2.0 metal/s).
    • Start boxes are drawn in the BAR lobby, not stored in the map. The map stores start positions.
    • Your work is autosaved in this browser. Use Save to keep a project file (.barmap) you can reopen later.
